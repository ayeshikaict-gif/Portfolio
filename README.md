## 🎨 Key Features & Design System

-  **Apple-Inspired Aesthetics**: Crisp white canvas (`#FFFFFF`), signature `#F5F5F7` surfaces, dark typography (`#1D1D1F`), subtle borders (`rgba(0,0,0,0.06)`), and `#2997FF` electric blue accent.
- 📱 **Apple Bento Small Tile Grid**: Compact bento grid for project showcases featuring real screenshot previews, interactive viewport device frame modals, and quick category filtering.
- 🎓 **Education Spec Cards**: Highlights 5 academic qualifications (University of Vavuniya Honours Degree, IMBS Diplomas in ICT & English, LPEC Diploma in HRM, Success IT College Diploma in CS) featuring official circular institution logos.
- 💻 **Abstract 3D Interactive Hero**: Interactive mouse-tilt panel featuring live syntax highlighting, live system status, and core stack tags.
- 📜 **Linked Credentials**: All 7 certifications include direct verification links to LinkedIn credentials.
- ✉️ **Interactive Contact System**: Get in touch modal with mail dispatch directly to `ayeshika.ict@gmail.com`, copy-to-clipboard integration, and celebratory confetti effects.

## 🚀 Getting Started & Local Setup

### Prerequisites
- Node.js (v18.0.0 or higher)
- npm (v9.0.0 or higher)

### Installation Steps

1. **Clone the repository**:
   ```bash
   git clone https://github.com/ayeshikaict-gif/portfolio-sachini.git
   cd portfolio-sachini
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the local development server**:
   ```bash
   npm run dev
   ```
   Open your browser and navigate to `http://localhost:5173/`.

4. **Build for production**:
   ```bash
   npm run build
   ```
